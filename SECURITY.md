# Security

Only the current main branch receives fixes. Do not put security reports, secrets, private records or exploit payloads in public issues. Use GitHub private vulnerability reporting when available. If private reporting is unavailable, open a public issue requesting a private contact without including sensitive details.

Public code accepts local private inputs but never authorizes their upload. Tests use synthetic inputs. CI has read-only repository access and no private dataset or credentials. The privacy scanner is a heuristic, not an anonymizer or a substitute for manual review. Never use it as proof that photos are safe to publish.
